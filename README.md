# Sistema de Registro de Usuarios

Tarea que el profesor nos colocó para practicar de Excepciones en java.

El ejercicio trata de un sistema de registro de usuarios, el cual al momento de capturar los datos de entrada del usuario (Nombre, edad, correo electrónico, salario), debe de saltarle un error al usuario, indicándole cúal fue el error que cometió; sin finalizar el programa por completo, permitiéndole volver a ingresar los datos solicitados, así hasta que el ususario que ingrese los datos decidad salir del programa.

## Como ejecutar el programa

Dento de la carpeta de src, ejecute en la consola "javac Main.java", luego "java Main.java"; después de eso, le debería aparecer en la consola un menú con las siguientes opciones: 1. Registrar Usuario; 2. Salir. Elija una de esas dos opciones; la primera para ingresar los datos solicitados por el programa, y la segunda para cerrar el programa por completo.
